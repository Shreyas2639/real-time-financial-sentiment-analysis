# GitHub upload checklist

- Upload the files and folders in this package.
- Do not upload trained checkpoints, virtual environments, API keys, generated plots, or local evaluation JSON files.
- Do not upload the complete published chapter PDF; cite it through its DOI instead.
- Keep `data/financial_news.csv` uncommitted until every original Kaggle URL and licence is documented.
- Choose a software licence only after all project authors agree.
- After creating the repository, add its URL to `CITATION.cff` if desired.
- Run `pytest -q` once before the first push.
